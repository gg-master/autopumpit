# autopumpit

Минимальная основа автополива на Arduino Uno (ATmega328P): прошивка AlexGyver
`auto-pumps_v2.1` для **14 отдельных помп**, локальные библиотеки и схема Wokwi.
Каждый канал имеет собственные время работы и паузу. По умолчанию помпы
работают независимо (`PARALLEL = 1`): запуск одной не ждёт остановки другой.
Управляющий уровень — высокий (`SWITCH_LEVEL = 1`).
Версия с общей помпой и клапанами сюда не входит.

## Структура

```text
src/main.cpp               прошивка: setup(), loop(), таймеры и меню
src/rtc_schedule.cpp       RTC и сохранение следующего срока полива
include/config.h           параметры и пины
include/channel_names.h    названия 14 каналов
lib/                       четыре используемые библиотеки с исходниками в src/
docs/upstream.md           происхождение и отличия от оригинала
docs/verification.md       результаты проверки
platformio.ini             сборка C++ для Uno / Arduino framework
wokwi.toml                 пути к собранной прошивке
diagram.json               исходная схема с добавленным DS1307
.vscode/                   рекомендуемые расширения и задача сборки
```

Используется обычная структура C++ проекта PlatformIO. Arduino остаётся
аппаратным фреймворком; промежуточный скетч `.ino` и CMake не нужны.
Исходные четыре библиотеки лежат в `lib/`. RTClib 2.1.4 и Adafruit BusIO 1.17.4
загружаются PlatformIO по закреплённым версиям. Стандартные `Wire` и EEPROM
предоставляет Arduino framework. Старые версии и доработки Auto-Pumps не перенесены.

## Сборка и запуск в Wokwi

1. Открыть эту папку в VS Code. Установить расширения **PlatformIO IDE** и
   **Wokwi Simulator** из списка рекомендаций.
2. Выполнить **PlatformIO: Build**. Альтернатива из терминала:

   ```powershell
   python -m pip install --user platformio
   python -m platformio run
   ```

   Если PlatformIO Core уже доступен в PATH, достаточно `pio run`.
   При первой сборке нужен интернет для загрузки AVR toolchain и Arduino framework.
3. Убедиться, что появились `.pio/build/uno/firmware.hex` и `firmware.elf`.
4. Через F1 выполнить **Wokwi: Start Simulator**. При необходимости выполнить
   предложенную расширением авторизацию/активацию Wokwi.

`Ctrl+Shift+B` также запускает сборку через `python -m platformio run`.
Файлы сборки генерируются локально и исключены из Git.

## Подключение

| Назначение | Пины Uno |
| --- | --- |
| Помпы 1–10 | D4–D13 соответственно |
| Помпы 11–14 | A0–A3 как цифровые выходы |
| Энкодер CLK / DT / SW | D3 / D2 / D0 |
| LCD SDA / SCL | A4 / A5 |
| LCD I2C | `0x27` (`DRIVER_VERSION = 1`) |
| RTC SDA / SCL | A4 / A5, общая шина с LCD |
| RTC питание | 5V / GND |
| RTC I2C | `0x68` |

В `diagram.json` сохранена исходная схема из `Auto-Pumps/diagram.json`:
расположение существующих компонентов, повороты, цвета и маршруты всех проводов.
Слева от дисплея добавлен RTC DS1307 и четыре провода к нему.
В симуляции показан один канал: D4 управляет `relay1`, а его контакты
COM/NO включают красный светодиод `led1`, который изображает нагрузку.
Реле Wokwi по умолчанию имеет тип `npn` и включается высоким уровнем.
Поэтому в `include/config.h` установлен `SWITCH_LEVEL = 1`: «РАБОТА» означает
замкнутые COM–NO и горящую лампочку, «ПАУЗА» — разомкнутые COM–NO.
Для физического реле с активным LOW этот параметр нужно заменить на `0`.

Прошивка продолжает обслуживать 14 каналов; выходы остальных 13 в этой
диаграмме не подключены.

Дополнительный `sw1` — переключатель для имитации удержания кнопки энкодера
в симуляторе. Его общий контакт подключён к D0, как и кнопка энкодера.
Соединение с GND (контакт 3) означает «кнопка удерживается», соединение
с +5 В (контакт 1) — «кнопка отпущена». Можно включить удержание,
повернуть энкодер и вернуть переключатель обратно.

На реальном устройстве помпы подключаются через драйверы/реле и отдельное
питание, а не напрямую к GPIO. D0 занят кнопкой энкодера,
поэтому Serial RX не свободен.

## Первый небольшой шаг

При первом запуске настройки нулевые, все каналы выключены.

- Поворот энкодера перемещает стрелку между выбором помпы и полями времени.
- Удержание кнопки с поворотом меняет выбранное значение.
- На строке выбора помпы удержание с поворотом выбирает `Pump 1` … `Pump 14`.
- Далее задаются часы, минуты и секунды **ПАУЗЫ**, затем **РАБОТЫ**.
- Для сохранения настроек вернуться стрелкой к выбору помпы (верхняя строка).
- Чтобы увидеть результат быстро, задать паузу 00:00:05 и работу 00:00:02
  для первой помпы. Реле должно включать красный светодиод на две секунды.
- Нулевое значение паузы или работы отключает канал.
- Удержание кнопки при включении сбрасывает настройки всех каналов;
  после сброса кнопку нужно отпустить.

Пауза по умолчанию отсчитывается от выключения помпы (`TIMER_START = 1`).
После сохранения настроек первый полив назначается через паузу. После
перезапуска восстанавливается сохранённый срок, с учётом времени без питания.
Каждый просроченный канал запускается один раз; несколько помп могут работать одновременно.
Подсветка отключается после 60 секунд
бездействия; первый поворот будит дисплей, следующие меняют настройки.

Параметры находятся в `include/config.h`, названия каналов — в `include/channel_names.h`.

## Часы и отключение питания

Профиль `uno` использует DS1307 для Wokwi. Для физического DS3231:

```powershell
python -m platformio run -e uno-ds3231
```

Батарейка RTC сохраняет ход часов, EEPROM Arduino — настройки и следующий срок.
Прерванный полив не продолжается; при загрузке все реле сначала выключены.
Если RTC недоступен, появляется `RTC error`, полив заблокирован до исправления
подключения и перезапуска. Подробности и сценарий проверки — в [docs/rtc.md](docs/rtc.md).
