# AutoPumpIt

**Автополив растений на Arduino Uno: своё расписание и ручное управление для каждой помпы.**

AutoPumpIt управляет до **14 отдельных помп** через реле или драйверы.
Для каждого растения можно задать дату первого полива, длительность работы
и паузу между поливами. Настройка выполняется энкодером на LCD1602;
сначала попробовать проект можно в Wokwi.

- **Автоматический полив:** первый запуск по дате и времени, затем повторение с заданной паузой.
- **Ручной полив:** собственное время, «ПУСК» и «СТОП» для выбранной помпы.
- **Общий лимит помп:** от 1 до 14 одновременных запусков; по умолчанию работает одна.
- **Сохранение расписания:** RTC ведёт часы, EEPROM хранит программу и следующий срок.
- **Русский и английский интерфейс:** язык выбирается при сборке, надписи можно редактировать.

Проект основан на AlexGyver Auto-Pumps v2.1. Происхождение исходников
и библиотек описано в [документации](docs/upstream.md).

## Пользователю

### Что потребуется

| Для устройства | Для запуска на компьютере |
| --- | --- |
| Arduino Uno, LCD1602 с I2C и энкодер с кнопкой | VS Code и PlatformIO IDE |
| RTC DS1307 или DS3231 с батарейкой | Wokwi Simulator для симуляции |
| Помпы, подходящие драйверы/реле и питание | Интернет при первой сборке |

Помпы подключаются через драйверы или реле с отдельным питанием.
В комплектной схеме Wokwi одна нагрузка показана светодиодом через реле;
прошивка обслуживает все 14 каналов.

### Первый запуск

1. Скачайте проект и откройте его папку в VS Code.
2. Установите рекомендованные расширения **PlatformIO IDE** и **Wokwi Simulator**.
3. В PlatformIO соберите профиль `uno` и выполните **Wokwi: Start Simulator**.
4. Проверьте часы. Выберите помпу, задайте дату старта, паузу и работу, затем сохраните.

[Подробное руководство](docs/getting-started.md) содержит схему подключения,
назначение пинов, выбор RTC, сборку, загрузку на плату и особенности Wokwi.

### Как управлять

| Действие | Результат |
| --- | --- |
| Поворот энкодера | Выбор поля или действия |
| Удержание с поворотом | Изменение значения; на заголовке — выбор помпы |
| Короткое нажатие на заголовке | Меню «АВТО / РУЧНОЙ / ЧАСЫ / ЛИМИТ ПОМП» |
| Долгое нажатие на заголовке | Сброс настроек выбранного режима этой помпы |

**Авто:** задайте будущие дату и время первого запуска, паузу и длительность работы.
После первого полива следующий срок отсчитывается от окончания работы плюс пауза.
Нулевая пауза или работа отключает автоматическую программу.

**Ручной:** выберите «РУЧНОЙ», установите время и нажмите «ПУСК».
«СТОП» останавливает только выбранную помпу. Если лимит занят, запрос ждёт
в очереди; отсчёт начинается при фактическом включении. Можно перейти
к другой помпе, пока первая работает.

**Лимит:** выберите «ЛИМИТ ПОМП», измените число и нажмите «ЗАПИСЬ».
Настройка действует сразу и сохраняется после отключения питания.

При восстановлении питания прерванная доза не продолжается. Сохранённая
автоматическая программа остаётся; ручные запуски не восстанавливаются.

Подробнее: [расписание](docs/schedule.md) · [ручной режим и лимит](docs/manual.md) ·
[часы и отключение питания](docs/rtc.md) · [язык и названия растений](docs/i18n.md).

## Разработчику

Прошивка написана на C++ с Arduino framework и собирается PlatformIO.
Утилиты и сценарии тестирования написаны на Python. Core отделён от LCD
и аппаратного адаптера; нативные тесты запускают настоящий C++ код прошивки.

Для терминала установите [uv](https://docs.astral.sh/uv/getting-started/installation/).
Из корня проекта выполните:

```text
uv sync --locked
uv run python -m tools.check
```

Полная проверка запускает линтер, форматирование, проверку типов, тесты,
проверку переводов и четыре сборки прошивки. Команды одинаковы для Windows,
Linux и macOS. На macOS нужны Xcode Command Line Tools; на Windows и Linux
компилятор тестовых стендов устанавливается автоматически.
