# RTC и восстановление расписания

[Главная](../README.md) · [Все документы](README.md)

RTC DS1307 используется в Wokwi (профиль uno), DS3231 — на реальном устройстве
(uno-ds3231). Адрес 0x68, SDA A4, SCL A5; LCD остаётся на той же шине (0x27).
Батарейка сохраняет ход часов без основного питания.

Дата первого включения, очередь, настройка часов и примеры отключения питания
описаны в [schedule.md](schedule.md). Ручная очередь — в [manual.md](manual.md).

При сохранении задаётся точный будущий срок, а не «сейчас + пауза». Следующий
после полива срок считается от фактического выключения плюс пауза
(TIMER_START=1). Восстановленный просроченный канал получает один полив,
затем обычную паузу. При лимите по умолчанию 1 каналы работают последовательно;
при большем лимите могут работать одновременно в пределах заданного числа.

При загрузке все выходы выключены. Прерванная доза не возобновляется:
очередной срок сохранён до включения реле. Ручная очередь хранится только
в RAM. Отказ или перевод RTC назад во время работы вызывает RTC error,
все выходы выключаются до исправления подключения и перезапуска.

Если RTC остановлен, сообщает потерю хода либо содержит невалидную дату,
открывается обязательная настройка часов. Сохранённые сроки не стираются
и не перебазируются на время сборки. После подтверждения правильных часов
будущие сроки продолжают ожидаться, просроченные обслуживаются по очереди.
Из Select mode -> Set clock часы можно установить вручную; эта операция
останавливает текущие помпы и отменяет ручную очередь. Вводится местное время,
часовой пояс и DST автоматически не пересчитываются.

## EEPROM

Единственный формат программы находится в 128–631: две записи по 18 байт
на помпу (версия, номер записи, следующий срок, пауза, работа, CRC16 и маркер).
Настройки и срок фиксируются вместе; RAM меняется после завершения записи.
При загрузке выбирается последняя корректная запись. Если обе копии потеряны,
канал отключён. Область 0–111 не используется: прежние настройки из неё не
читаются и в неё ничего не записывается; миграции нет. Флаг запуска — 1023.
Общий лимит помп хранится отдельно в 632–647.

Новая запись идёт в старшую по возрасту копию с маркером последним. До
включения реле запись физически завершается. При обрыве остаётся предыдущая
валидная копия. При нажатой кнопке энкодера во время загрузки настройки
и сохранённые сроки сбрасываются; кнопку затем нужно отпустить.

Восстановление тестируется новым CPU с прежней EEPROM и продвинутым RTC.
Stop/Start Wokwi может пересоздавать EEPROM/RTC, поэтому он сам по себе
не доказывает поведение реального отключения питания.
