# Подключение и первый запуск

[Главная](../README.md) · [Все документы](README.md)

## Комплектующие

- Arduino Uno на ATmega328P.
- LCD1602 с интерфейсом I2C и энкодер с кнопкой, например KY-040.
- RTC DS1307 или DS3231 с батарейкой.
- От одной до 14 отдельных помп, подходящие драйверы/реле и питание.
- Для загрузки на плату — USB-кабель; для проверки без устройства — Wokwi в VS Code.

GPIO управляет входами драйверов или реле. Помпы получают питание отдельно
и напрямую к GPIO не подключаются. Проект рассчитан на отдельную помпу
для каждого канала; схема с одной общей помпой и клапанами не поддерживается.

## Подключение

Расположение компонентов и проводов в симуляции задано в [diagram.json](../diagram.json).
Настройки пинов и управляющих уровней — в [config/settings.h](../config/settings.h).

| Назначение | Подключение Uno по умолчанию |
| --- | --- |
| Выходы помп 1–10 | D4–D13 соответственно |
| Выходы помп 11–14 | A0–A3 как цифровые выходы |
| Энкодер CLK / DT / SW | D3 / D2 / D0 |
| LCD и RTC: SDA / SCL | A4 / A5, общая шина I2C |
| LCD, RTC и энкодер: питание логической части | 5V / GND |
| Адрес LCD | `0x27` при `DRIVER_VERSION = 1` |
| Адрес RTC | `0x68` |

D0 занят кнопкой энкодера, поэтому Serial RX не свободен.
По умолчанию `SWITCH_LEVEL = 1`: выход HIGH включает нагрузку.
Для драйвера или реле с активным LOW задайте `SWITCH_LEVEL = 0` и пересоберите
прошивку. Перед включением режима OUTPUT программа предустанавливает неактивный уровень.

## Сборка и симуляция в Wokwi

1. Скачайте проект и откройте его корневую папку в VS Code.
2. Установите расширения **PlatformIO IDE** и **Wokwi Simulator**,
   предложенные в [.vscode/extensions.json](../.vscode/extensions.json).
3. Откройте PlatformIO → Project Tasks → `uno` → General → **Build**.
   При первой сборке требуется интернет для загрузки инструментов и библиотек.
4. Сборка создаст `.pio/build/uno/firmware.hex` и `firmware.elf`.
   Именно их использует [wokwi.toml](../wokwi.toml).
5. Через палитру команд VS Code выполните **Wokwi: Start Simulator**.
   При необходимости выполните предложенную расширением авторизацию.

Терминальная альтернатива после установки [uv](https://docs.astral.sh/uv/getting-started/installation/):

```text
uv sync --locked
uv run python -m platformio run -e uno
```

Задача **Build firmware** по `Ctrl+Shift+B` также использует uv.
Если собираете через PlatformIO IDE, uv для самой сборки не требуется.

### Особенности комплектной схемы

- Подключён один канал: D4 управляет `relay1`, контакты COM–NO включают
  красный светодиод `led1`, изображающий нагрузку. «РАБОТА» — светодиод горит,
  «ПАУЗА» — выключен. Остальные 13 выходов прошивки в диаграмме не подключены.
- Часы представлены DS1307; LCD и RTC подключены к общей шине I2C.
- `sw1` на D0 имитирует удержание кнопки энкодера: контакт 3 (GND) — удерживается,
  контакт 1 (+5V) — отпущена. Для изменения поля включите удержание,
  поверните энкодер и верните переключатель обратно.
- После отпускания без поворота длительное удержание может вызвать сброс
  выбранного режима помпы. Удержание с поворотом сброса не вызывает.

## Загрузка на реальную плату

Подключите Uno по USB и выберите профиль своего RTC в PlatformIO:

| RTC | Профиль с русским интерфейсом | С английским |
| --- | --- | --- |
| DS1307 | `uno` | `uno-en` |
| DS3231 | `uno-ds3231` | `uno-ds3231-en` |

В Project Tasks выбранного профиля выполните **Build**, затем **Upload**.
Из терминала, например для DS3231:

```text
uv run python -m platformio run -e uno-ds3231 -t upload
```

Если подключено несколько плат, явно выберите порт загрузки средствами PlatformIO.
Выбор языка при сборке и собственные названия растений описаны в [i18n.md](i18n.md).

## Первый полив

1. Проверьте местные дату и время в меню «ЧАСЫ». При потере хода RTC
   настройка открывается автоматически; предложенное время нужно проверить.
2. На заголовке удержанием с поворотом выберите помпу.
3. Обычным поворотом вправо перейдите к дате первого запуска.
4. Задайте будущие день, месяц, год, часы и минуты, затем паузу и работу.
   Обычный поворот выбирает поле, удержание с поворотом меняет его.
5. Выберите «ЗАПИСЬ» и нажмите кнопку. На основном экране появится следующий
   срок `ДД.ММ ЧЧ:ММ:СС`. Год остаётся доступен в редакторе даты.

По умолчанию помпы работают по одной. Изменить это можно в «ЛИМИТ ПОМП»;
значение общее для автоматического и ручного полива и сохраняется в EEPROM.
Нулевая пауза или работа отключает автоматическую программу помпы.

Для немедленного полива коротко нажмите на заголовке, выберите «РУЧНОЙ»,
задайте длительность и нажмите «ПУСК». «СТОП» действует только на эту помпу.
