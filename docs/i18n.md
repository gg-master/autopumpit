# Язык интерфейса и названия растений

[Главная](../README.md) · [Все документы](README.md)

Язык выбирается при компиляции. По умолчанию включён русский.
В `config/settings.h` параметр `UI_LANGUAGE`: `1` — русский, `0` — английский.
После изменения пересоберите прошивку и перезапустите Wokwi.

Готовые профили PlatformIO:

| Модуль часов | Русский (по умолчанию) | Английский |
| --- | --- | --- |
| DS1307 / Wokwi | uno | uno-en |
| DS3231 | uno-ds3231 | uno-ds3231-en |

Пример: `uv run python -m platformio run -e uno-en`.
Английские профили задают UI_LANGUAGE=0 флагом компилятора независимо от `config/settings.h`.
Wokwi сейчас читает прошивку из .pio/build/uno. Для английского в Wokwi проще
выставить `UI_LANGUAGE=0` в `config/settings.h` и собрать профиль uno.

## Как изменить надписи

- config/locales/ru.h — русский каталог в UTF-8.
- config/locales/en.h — английский каталог.
- Сохраняйте имена TXT_… и подстановки %u, %02u, %c, %s.
- Максимум 16 символов в строке; для имени помпы — 15 из-за указателя выбора.
- Для русского предпочтительны прописные буквы: они требуют меньше специальных знаков.
- Две строки одного экрана могут использовать максимум 7 разных специальных букв.
  Буквы, похожие на латинские (А, В, Е, К и другие), специальных знаков не требуют.
  Ограничение связано с кэшем используемой библиотеки LCD1602.
- Проверка после правок: `uv run python -m tools.check_translations`. Она проверяет
  оба каталога, подстановки, длины строк, пары кнопок и запас специальных знаков.

Переводы хранятся во Flash. В прошивку входит только выбранный каталог.
Строки обрезаются по символам, а не по байтам UTF-8.
Переключения языка в работающем меню нет.

## Имена растений

По умолчанию имена автоматически переводятся как «ПОМПА 1» / «Pump 1».
Для своих названий включите USE_CUSTOM_CHANNEL_NAMES=1 в config/channel_names.h
и измените таблицу relayNames в том же файле. Имена сохраняйте в форме L"Имя".
Проверка каталогов не проверяет эту пользовательскую таблицу: следите за длиной
имён и общим набором специальных букв вместе с нижней строкой экрана.

## Названия пунктов меню

Auto → АВТО; Manual → РУЧНОЙ; Set clock → ЧАСЫ; Next → ДАЛЕЕ;
Back → НАЗАД; Start → ПУСК; Stop → СТОП; Save → ЗАПИСЬ;
Cancel → ОТМЕНА; Pause → ПАУЗА; Run → РАБОТА; Pump limit → ЛИМИТ ПОМП.
В настройке часов сохранение обозначено «ОК», чтобы обе кнопки поместились рядом со временем.
