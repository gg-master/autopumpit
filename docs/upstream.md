# Происхождение исходников

Основа: [AlexGyver/Auto-Pumps](https://github.com/AlexGyver/Auto-Pumps),
ревизия [`4f7786a799aaf865ca94539b66c56af524ba4d24`](https://github.com/AlexGyver/Auto-Pumps/tree/4f7786a799aaf865ca94539b66c56af524ba4d24).

Локальный старый проект: `D:/dev/arduino/Auto-Pumps`.
Его папка `Новая версия!!!/прошивка/auto-pumps_v2.1` уже изменена под одну помпу.
Для чистой основы использованы исходники закреплённой upstream-ревизии,
а не предыдущая переработка `firmware/auto_pumps`.

## Перенос

- `Новая версия!!!/прошивка/auto-pumps_v2.1/auto-pumps_v2.1.ino`
  перенесён в `src/main.cpp`. Добавлены `Arduino.h` и явные объявления функций,
  которые Arduino IDE обычно генерирует автоматически.
- Конфигурация вынесена в `include/config.h`: 14 каналов вместо восьми,
  названия `Pump 1` … `Pump 14`, адрес LCD `0x27` вместо `0x3f`.
  `SWITCH_LEVEL = 1` согласован с активным HIGH реле Wokwi (`npn` по умолчанию).
- Из `Новая версия!!!/библиотеки/` перенесены `GyverEncoder` (3.1),
  `EEPROMex`, `LCD_1602_RUS` (1.0.3), `LiquidCrystal_I2C-master` (1.1.2).
  Последняя папка переименована в `lib/LiquidCrystal_I2C`.
- Исходники библиотек перенесены без изменений. Сохранены доступные README,
  метаданные, LICENSE и авторские уведомления в исходниках. Отдельная общая
  лицензия на весь новый проект не назначалась.
- Не перенесены неиспользуемая параллельная `LiquidCrystal`, примеры библиотек,
  старые версии, объектные файлы `.o` и чужие результаты сборки.
- `diagram.json` скопирован без изменений из `D:/dev/arduino/Auto-Pumps/diagram.json`.
  Сохранены один канал через реле с LED-нагрузкой, переключатель удержания на D0,
  координаты элементов и все маршруты проводов. Прошивка поддерживает 14 каналов.

## Минимальные исправления оригинала

1. В двух циклах очистки EEPROM `byte` заменён на `uint16_t`, шаг — размер
   `uint32_t`. В исходнике восьмибитный счётчик не достигает 500 и зацикливается.
2. При старте наличие ненулевых паузы и времени работы, состояние канала и
   очередь проверяются также при `startFlag`. Иначе первый проход включает
   все выходы, а каналы с нулевым временем работы не выключаются.
3. Таймаут подсветки умножается на `1000UL`: выражение `60 * 1000` переполняет
   16-битный `int` AVR. Для периода также явно используется `1000UL`.

Меню, формат EEPROM и основной алгоритм v2.1 сохранены. Новые функции старого
проекта сюда не добавлялись.

## Следующий небольшой шаг: RTC

Добавлены `src/rtc_schedule.cpp` и `include/rtc_schedule.h`: только часы и
сохранение следующего срока полива, без статистики и календарных страниц.
В `main.cpp` убран немедленный старт при загрузке; запуск теперь определяется
сохранённым сроком. Активный полив продолжает измеряться через `millis()`.
Названия каналов выделены из общего `config.h` в `channel_names.h`, чтобы
модуль расписания не создавал вторую неиспользуемую таблицу строк.
Добавлены закреплённые RTClib 2.1.4 / Adafruit BusIO 1.17.4 и профили DS1307/DS3231.
В пользовательскую диаграмму добавлены только RTC и четыре его соединения;
исходные элементы и пути проводов сохранены. Подробности — в `rtc.md`.
