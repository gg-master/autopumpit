# Происхождение исходников

[Главная](../README.md) · [Все документы](README.md)

## Основа проекта

AutoPumpIt основан на [AlexGyver/Auto-Pumps](https://github.com/AlexGyver/Auto-Pumps),
ревизия [`4f7786a799aaf865ca94539b66c56af524ba4d24`](https://github.com/AlexGyver/Auto-Pumps/tree/4f7786a799aaf865ca94539b66c56af524ba4d24).
Взята новая версия `auto-pumps_v2.1` с отдельными выходами для помп.
Старые версии и вариант с общей помпой и клапанами не переносились.

Исходный скетч стал основой прошивки C++ для PlatformIO. Затем появились
календарный запуск, RTC и сохранение расписания, точечный ручной полив,
изменяемый лимит помп и переводы. Core, аппаратный адаптер и LCD-интерфейс
разделены; текущие меню и хранение программы уже отличаются от оригинала.
Структура описана в [architecture.md](architecture.md).

## Библиотеки

Из набора библиотек новой версии перенесены в [lib/](../lib/):

| Библиотека | Происхождение/назначение |
| --- | --- |
| GyverEncoder 3.1 | Энкодер и кнопка |
| LCD_1602_RUS 1.0.3 | Кириллица на LCD1602 |
| LiquidCrystal_I2C 1.1.2 | I2C-дисплей; исходная папка `LiquidCrystal_I2C-master` переименована |
| EEPROMex | Сохранена из исходного набора; текущий адаптер использует AVR EEPROM напрямую |

Исходники этих библиотек сохранены без изменений вместе с доступными README,
метаданными, LICENSE и авторскими уведомлениями. Неиспользуемая параллельная
LiquidCrystal, примеры, старые версии и готовые объектные файлы не переносились.

RTC использует RTClib 2.1.4 и Adafruit BusIO 1.17.4; зависимости закреплены
в [platformio.ini](../platformio.ini). Wire и AVR EEPROM предоставляет
Arduino framework. Отдельная общая лицензия на весь проект не назначалась;
авторские уведомления исходных компонентов остаются в их файлах.

## Схема Wokwi

В комплектной диаграмме подключён один канал через реле со светодиодной
нагрузкой, LCD1602, энкодер и RTC DS1307. Переключатель на D0 имитирует
удержание кнопки энкодера. Прошивка обслуживает 14 каналов, хотя в диаграмме
подключена одна нагрузка.

Текущая схема — [diagram.json](../diagram.json), подключение и запуск —
[getting-started.md](getting-started.md).

## Исправления при первоначальном переносе

- В циклах очистки EEPROM восьмибитный счётчик заменён на `uint16_t`,
  чтобы он мог достигнуть адресов больше 255 без зацикливания.
- Убрано включение всех выходов на первом проходе и работа каналов
  с нулевой длительностью.
- Расчёты миллисекунд используют `1000UL`, чтобы не переполнять
  16-битный `int` AVR.

Это описание происхождения проекта. Пользовательские инструкции и команды
разработки находятся в отдельных документах.
